Ringkasan

Mangrovepreneurs menghubungkan perangkat di sarang kelulut dengan aplikasi mobile agar kondisi sarang dapat dipantau dari data sensor. Proyek ini dikembangkan untuk kebutuhan tim Fakultas Ekonomi dan Bisnis Universitas Lambung Mangkurat.

Konteks proyek adalah ajang nasional Innovilleague 2026 yang diselenggarakan Kementerian Koordinator Bidang Pemberdayaan Masyarakat RI. Pengembangan mencakup perakitan perangkat ESP32, integrasi sensor, koneksi database realtime, dan aplikasi Flutter.

ESP32BME280Load cell + HX711Firebase Realtime DatabaseFlutter / Dart

Fitur utama

Pemantauan suhu & kelembapan

Sensor BME280 membaca suhu dan kelembapan di sarang. Data dikirim melalui ESP32 agar dapat dilihat di aplikasi.

Indikator kesiapan panen

Load cell dengan modul HX711 membaca berat. Notifikasi kesiapan panen mengikuti target berat dalam kilogram yang diatur pengguna.

Notifikasi kondisi sarang

Aplikasi memberi notifikasi saat suhu atau kelembapan berada di bawah ambang yang ditentukan, serta saat target berat panen tercapai.

Ambang dapat diatur

Pengguna dapat mengatur batas suhu, kelembapan, dan target berat panen dari aplikasi Flutter sesuai kebutuhan sarang.

Implementasi

01

Sensor & ESP32

BME280 menangani pembacaan suhu dan kelembapan. Load cell terhubung melalui HX711 untuk pembacaan berat; ESP32 mengumpulkan data kedua jalur sensor.

02

Firebase Realtime Database

ESP32 mengirim data sensor ke Firebase Realtime Database, yang menjadi penghubung antara perangkat dan aplikasi mobile.

03

Flutter & notifikasi

Aplikasi Flutter menampilkan data sarang dan menyediakan pengaturan ambang. Kondisi suhu, kelembapan, serta berat digunakan untuk menentukan notifikasi.
