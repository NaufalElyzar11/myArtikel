Overview Proyek

Wasaka Hexapod (Hexaka V3) adalah generasi terbaru robot berkaki enam yang dikembangkan oleh Wasaka Robotic Team. Robot dirancang untuk mengatasi kelemahan mobilitas robot beroda saat berhadapan dengan medan berkontur tidak rata, tangga, dan permukaan berbatu.

Berbeda dari platform konvensional yang mengandalkan banyak sensor jarak (ultrasonik/LiDAR) yang mahal dan rumit secara kabel, Hexaka V3 dirancang khusus untuk kompetisi BRIN Exhibition on Smart Technology (BEST) 2026 dengan kemampuan bernavigasi secara otonom di lintasan berundak hanya mengandalkan satu sensor kamera melalui fusi algoritma Computer Vision dan Deep Learning.

Tiga Misi Utama Hexaka V3

Basis kode Hexaka V3 menyatukan fungsionalitas robot ke dalam tiga aplikasi operasional siap pakai:

1
Autonomous Navigation (Kompetisi BEST 2026)

Navigasi mandiri dengan multi-layer vision perception (analisis tepian, Optical Flow, segmentasi lantai, dan estimasi area bebas rintangan), penghindaran rintangan berbasis YOLO11 ONNX, stabilisasi kemiringan bodi tertutup (closed-loop PID leveling), dan mesin status Finite State Machine (CRUISE, AVOID, BACKUP, SCAN, FAULT).

2
Person Following & Teleoperation (Demo Pameran PKKMB)

Pelacakan orang (human tracking) cerdas menggunakan model YOLOv8 ONNX berkecepatan tinggi dengan filter histeresis anti-flicker, pengendali jarak dan arah PID ganda, animasi interaktif (salam membungkuk, gerakan bernapas, lambaian kaki), serta opsi kendali manual jarak jauh stik Xbox via Pygame.

3
Interactive TikTok Live Streaming & 3D Digital Twin

Robot terhubung langsung secara nirkabel ke siaran langsung TikTok Live via WebSocket real-time. Robot merespons hadiah penonton (gifts), likes, komentar, dan follow dengan koreografi fisik 18-DOF yang dilengkapi queue manager anti-tabrakan. Dilengkapi telemetri non-blocking UDP 50 Hz ke antarmuka 3D Digital Twin di peramban web.

Arsitektur Sistem Modular

Repositori Hexaka V3 mengadopsi standar arsitektur perangkat lunak robotika yang bersih, teruji, dan modular:

Lapisan Hardware & Kinematika

  • Driver Dynamixel AX-12A: Komunikasi serial paket berkecepatan tinggi dengan pengalamatan ID 1-18.
  • Kinematika Inversi (IK): Pemetaan koordinat kartesian (X, Y, Z) ke sudut rotasi coxa, femur, dan tibia.
  • Tripod Gait Engine: Siklus langkah di mana 3 kaki menyangga bodi (stance phase) sementara 3 kaki lainnya melangkah (swing phase).
  • IMU 9-DOF BNO055 & Leveler: Membaca orientasi roll, pitch, yaw untuk auto-leveling horizontal kontinu.
  • Layar OLED SSD1306 128x64: Menampilkan status sistem, tegangan, IP, dan logo tim secara asinkron.

Stack Perangkat Lunak & AI

Python 3 ROS2 ONNX Runtime YOLOv8 & YOLO11 OpenCV NumPy Dynamixel SDK BNO055 IMU SSD1306 I2C OLED Pygame (Xbox Controller) WebSockets & UDP Three.js (Digital Twin)

Alur Eksekusi & Pipeline Visi

A
Stream Kamera Multi-Index & Preprocessing

Worker thread membaca frame kamera dengan mekanisme fallback otomatis (indeks 0-5), melakukan normalisasi resolusi dan konversi warna optimal untuk inferensi AI.

B
Inferensi Neural Network Tervektorisasi

Model ONNX mendeteksi kontur rintangan dan keberadaan subjek manusia dengan akselerasi CPU/GPU ringan tanpa membebani thread komunikasi servo.

C
Decision Engine & Finite State Machine

FSM mengevaluasi status rute: jika aman robot tetap melangkah maju (CRUISE), jika terdeteksi halangan robot beralih menghindari (AVOID) atau berputar mencari celah (SCAN).

D
Kompensasi IMU & Kalkulasi Gait Kinematika

Sudut kemiringan medan dikoreksi oleh kontroler PID body leveling sehingga bodi utama tetap datar. Kaki yang melangkah diatur koordinatnya melalui Inverse Kinematics.

E
Transmisi Paket Servo & Streaming Telemetri

Nilai target register posisi dikirimkan serentak ke 18 servo Dynamixel, bersamaan dengan pancaran data posisi dan orientasi UDP ke stasiun monitoring.

Hasil Pengujian & Pencapaian

  • Finalis BRIN BEST 2026: Sukses terpilih sebagai finalis kompetisi riset teknologi cerdas Badan Riset dan Inovasi Nasional (BRIN) dengan inovasi navigasi otonom kamera tunggal.
  • Stabilitas Langkah Tinggi: Tripod gait menghasilkan traksi kokoh pada kemiringan hingga 20 derajat tanpa risiko terbalik berkat safety tilt interlock.
  • Modularitas Bersih (Clean Code): Arsitektur terpisah antara core kinematika, visi, aplikasi misi, dan alat kalibrasi memudahkan pengujian individual tanpa mengaktifkan servo fisik.
  • Juara 3 Kompetisi Robot STEM Indonesia: Berhasil meraih juara 3 kategori Robotik pada Kompetisi Robot STEM 2025.
