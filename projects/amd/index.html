Overview Proyek

PRONE.ID adalah inovasi agrikultur cerdas yang dikembangkan dalam program Akademi Madrasah Digital (AMD) yang diselenggarakan oleh Kementerian Agama Republik Indonesia bersama XL Axiata. Proyek ini memadukan wahana udara tanpa awak (UAV Drone) untuk pemetaan ortofoto dan penyemprotan terarah, dengan jaringan sensor IoT nirkabel untuk pemantauan parameter tanah.

Seluruh data yang dikumpulkan dari node sensor dikirimkan ke Raspberry Pi Station sebagai gateway lokal, kemudian disinkronisasikan ke web dashboard terpusat sehingga pengelola lahan dapat memantau kondisi hidrologi tanah dan mengarahkan rute penyemprotan secara presisi.

Masalah & Target

Tantangan Lapangan

  • Monitoring Luas Terbatas: Pemantauan manual pada lahan sawit ribuan hektar membutuhkan waktu berhari-hari dan rawan ketidakakuratan data.
  • Penyiraman & Pemupukan Boros: Praktik konvensional menyiram secara seragam tanpa memperhatikan kadar air aktual tanah, membuang sumber daya air.
  • Ketiadaan Data Historis: Fluktuasi kelembapan tanah dan suhu lingkungan tidak tercatat secara digital untuk analisis jangka panjang.

Solusi & Target

  • Pemetaan Pola Grid Otomatis: Menerbangkan drone dengan jalur waypoint terencana untuk memetakan luasan lahan dalam hitungan menit.
  • Penyemprotan Terfokus: Mengaktifkan sprayer hanya pada zona dengan indikasi kekeringan berdasarkan data sensor node.
  • Telemetri Real-time: Pengiriman data nirkabel periodik dari node sensor tanah menuju stasiun gateway dan dashboard visual.

Arsitektur Sistem

Sistem dibangun dengan arsitektur 3 pilar perangkat keras yang saling berkomunikasi melalui protokol radio nirkabel dan jaringan data:

Pilar Hardware

  1. UAV Drone: Dilengkapi modul flight controller, sistem navigasi GPS otonom, dan modul pompa relay sprayer terkalibrasi.
  2. In-situ Sensor Nodes: Unit pemancar bertenaga baterai surya dengan sensor suhu, kelembapan udara (DHT22), dan kelembapan tanah resistif/kapasitif.
  3. Raspberry Pi Station: Gateway sentral penerima paket data telemetry via transreceiver radio nRF24L01 / Wi-Fi dan penyaji web dashboard.

Teknologi & Tools

Python Raspberry Pi OS Arduino / C++ nRF24L01 Wireless DHT22 & Soil Moisture GPS Telemetry HTML5 & CSS3 JavaScript OpenStreetMap API SQLite

Alur Kerja Data

1
Perencanaan Misi & Pemetaan Udara

Drone diterbangkan mengikuti jalur grid ortogonal dengan overlap kamera 75% untuk menghasilkan peta komposit vegetasi lahan dan mengidentifikasi anomali kerapatan kanopi.

2
Akuisisi Data Sensor Tanah

Node sensor yang tersebar di titik-titik perkebunan mengukur kelembapan volumetric tanah secara berkala dan memancarkan paket data ke stasiun penerima.

3
Agregasi & Analisis di Gateway

Raspberry Pi memvalidasi checksum paket data, mengonversi sinyal analog ke satuan persentase kelembapan standar, dan menyimpan histori pembacaan ke database lokal.

4
Visualisasi & Aksi Penyiraman

Data disajikan pada dashboard pemantauan berbasis peta. Jika terdeteksi zona dengan kelembapan di bawah ambang batas, operator dapat mengarahkan drone untuk menyiram titik target secara presisi.

Hasil & Dampak

  • Efisiensi Penggunaan Air: Uji coba lapangan membuktikan pengurangan volume air hingga 22% dibandingkan metode penyiraman manual konvensional.
  • Peningkatan Kecepatan Survei: Survei kondisi perkebunan mencapai percepatan 31% dengan cakupan pemetaan udara otomatis beresolusi hingga ~3cm per pixel.
  • Penghargaan Nasional: Dinobatkan sebagai peraih The Most Attractive Team pada ajang kompetisi riset nasional Akademi Madrasah Digital (AMD) 2021/2022.
  • Validasi Prototype: Seluruh modul telemetry RF mampu mentransmisikan data stabil dalam radius operasional uji coba lapangan.
